# Chaitra R — Portfolio

Personal portfolio of **Chaitra R**, IB MYP/DP Design and Technology facilitator and design engineer based in Hyderabad. The layout is minimal and type-led, inspired by the [Ferral Studio](https://ferralstudio.framer.website/) Framer template. Colours and fonts match the CV: warm cream (`#F3EEE6`), forest green (`#2F5D50`), sage (`#77958D`) and a touch of clay, with Fraunces for headings and Karla for text.

## Pages

| Page | File | Contents |
| --- | --- | --- |
| Home | `index.html` | Statement headline, teaching areas, short about, references, contact |
| About | `about.html` | Bio, teaching philosophy, experience, education, skills and certifications |
| MYP Design | `myp.html` | Lesson plans (including Ardu's Lab) and student work |
| DP Design & Technology | `dp.html` | How I teach DP, lesson presentations, interactive tools, student work (CAD, simulation, and testing) |
| Other initiatives | `initiatives.html` | T-Works, Sreenidhi Ignite (photo gallery), SAIBSA, Makerspace |

The header and footer are repeated on every page, so a change to the nav or contact details needs to be made in all five files.
